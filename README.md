# Masami games

Small 3D games for a five-year-old, one folder per game. Each is its own Vite + React + TypeScript app on react-three-fiber; run it from its folder with `npm install` and `npm run dev`.

- [`chase/`](chase/README.md): a side-view cartoon police chase. Jump the rocks, cakes and worms; play as the police or the robber.
